# Conversor de Moedas

Aplicativo acadêmico criado com React Native, Expo e JavaScript.

## Executar

```bash
npx expo start
```

## Estrutura inicial

- `App.js`: componente raiz do aplicativo e contêiner de gestos.
- `index.js`: registro do componente raiz no Expo.
- `app.json`: configurações do projeto Expo.
- `assets/`: imagens padrão do projeto.
- `src/navegacao/`: Drawer principal e abas inferiores.
- `src/telas/`: telas Início, Sobre, Moedas, Favoritas e Converter.
- `src/componentes/`: componentes compartilhados pelas telas.

O Drawer abre Início e Sobre diretamente. A opção Moedas contém as abas Moedas,
Favoritas e Converter.
